# @tabler/flags-png

Country flags as PNG files, one directory per visual variant (`rounded`, `plain`, `gradient`, `shiny`) and per height in pixels (12, 16, 24, 32, 48, 64, 128).

```bash
pnpm add @tabler/flags-png
```

```
node_modules/@tabler/flags-png/dist/rounded/32/poland.png
```
